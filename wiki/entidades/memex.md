# Memex (Vannevar Bush, 1945)

> O ancestral intelectual deste cofre: um repositório pessoal e curado de documentos, ligados por **trilhas associativas** criadas pelo dono.

## O que se sabe

- Proposto por Vannevar Bush em 1945 — [[llm-wiki-padrao]].
- Visão: armazenamento pessoal, privado, ativamente curado, onde **as conexões entre documentos valem tanto quanto os documentos**.
- A web acabou indo para outro lugar: pública, algorítmica, não-curada. Bush estava mais perto disto aqui do que do que a web virou.
- **O que Bush não resolveu: quem faz a manutenção.** Trilhas associativas exigem trabalho humano contínuo, e é exatamente aí que sistemas assim morrem.

## Papel no meu contexto

O Memex é a peça que fecha o argumento de [[wiki-compilada-vs-rag]]. A ideia nunca foi ruim — faltava um agente disposto a fazer a escrituração para sempre. O LLM é a peça que estava faltando em 1945, não a ideia.

Serve também como aviso: se eu parar de manter, este cofre vira o que todo Memex humano virou — uma pasta de arquivos que ninguém abre.

## Relações

- Antecipa [[wiki-compilada-vs-rag]] — a intuição de que o valor está nas conexões compiladas.
- Contrasta com [[obsidian]] — o graph view é uma trilha associativa renderizada, 80 anos depois.
